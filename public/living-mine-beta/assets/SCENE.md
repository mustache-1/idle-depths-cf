# Settlement scene foundation

`ember-settlement-reference.jpeg` is an unchanged copy of the scene the user supplied and explicitly requested to use for the settlement. SHA-256: aa414169801d3342457c36da95d1ee123a1e69948bc1249e683738a52b4659cf.

Its composition is retained in full, without cropping, replacement illustration or repainting. Facility locations and statuses are HTML overlays scaled with the image. Construction and upgrades affect the existing simulation and live badges; the background itself is presently static. Later work can add separate animated layers and stage-specific furnishings using this same scene as the composition baseline. The source-controlled atlas remains for the separate mine scene. This supplied image is not described as original artwork authored during development.
